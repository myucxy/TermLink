# AI 消息显示修复（2026-10-04）

## Claude 正文重复

在 emulator-5556 的独立 DEV 中确认：同一 Claude 消息的 `/0` 和 `/1` 显示相同正文。
本机 Claude 原生记录中，同一 `message.id` 的 thinking 和 text 由两个独立 assistant
信封分别返回，每个信封的 `content` 数组只有一个元素。

Windows 原先把每个信封的数组下标当作完整消息的内容块下标。流式 thinking `/0` 被
最终 text `content[0]` 覆盖，而流式 text `/1` 仍在，形成两条正文。

现在保留当前原生消息的流式块类型和停止下标，将单块回执关联到对应块；使用回执 UUID
维持重复回执的原始关联。完整多块回执继续使用自身下标，工具仍用原生 tool ID。
不按正文相同与否删除消息，不改 Android/Server 协议。

此修复作用于 Windows 后续解析。已经落盘的重复历史未自动清洗，原先被覆盖的思考内容
也不能仅从 TermLink 快照恢复。本轮没有改写用户历史，没有升级运行中的客户端。

## 用户消息气泡

Android 内嵌 AI Web 页面改为随内容收缩的右对齐气泡，最大宽度为可用宽度的 88%
（上限 720px）。复制和追加草稿使用气泡外的弱化图标，保留 44px 触控区域和无障碍标签；
Markdown、代码、完整内容入口保留。原生兼容回退和 CLI 页面未改动。
