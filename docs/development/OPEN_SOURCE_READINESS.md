## 构建可移植性发现

- Android 原生构建仍有 Windows 工具默认路径，CMake 脚本也包含 Windows NDK 编译器路径；新环境应显式配置工具。不能声称 Linux runner 的 Android 全链路已验证。
- AI Web 的浏览器测试默认使用 Windows Edge，外部环境要配置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`。
- npm 锁文件包含既有镜像源；应在未来依赖维护中单独核验可达性和供应链，不为整理文档而改写锁文件。
- 一些旧测试脚本自带早期固定版本或机器路径。历史 README 中保留这些记录；运行前需查看脚本参数，不能复制旧命令直接作为新的正式构建。
- Android 原生适配器与 network-core 即使在 Relay Only 策略下仍可能需要编译。停用直连测试不等于可以删除这些构建依赖。
