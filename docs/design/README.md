## 本版设计依据

上一版把 CLI 和 AI 放进统一卡片后，两者的输入方式和视觉样式变得相似。本版只设计外层窗口编排，内部按现有 Android 界面复刻。默认并排打开一个 CLI 终端和一个 AI 对话，其余会话从“全部会话”或底部恢复；保留足够阅读面积。

| 区域 | 沿用的当前内容 | 实现依据 |
| --- | --- | --- |
| CLI 标题与连接 | 状态点、电脑名与会话名、控制中／只读、云朵菜单 | [ProductActivity.kt](../../android/app/src/main/kotlin/dev/termlink/product/ProductActivity.kt) 中的 `SessionDetail`、`SessionConnectionStatusMenu` |
| CLI 终端 | 黑底等宽文本，在终端内部直接输入；没有额外的聊天输入框或发送按钮 | 同文件 `TerminalSurface` |
| CLI 快捷键 | 两排 `键盘 / Esc / 退格 / ↑ / Del / Ctrl+C`、`粘贴 / Tab / ← / ↓ / → / Enter` | 同文件 `TerminalActionBar` 的默认两排布局 |
| AI 标题 | 返回会话列表、标题、Agent／电脑／工作目录、云朵菜单 | [AiPage.kt](../../android/app/src/main/kotlin/dev/termlink/product/AiPage.kt) 中的 `AiConversationHeader` |

| AI 输入 | 多行输入、附件／引用、授权方式、模型、推理强度、发送／停止、历史授权说明 | [AiComposerOptions.kt](../../android/app/src/main/kotlin/dev/termlink/product/AiComposerOptions.kt) 中的 `AiEnhancedComposer` |

新增部分仅为窗口外层的细标题条、拖动手柄、大小调整、展开与收起，以及平板工作台的窗口选择和排列。HTML 没有运行 Compose 或原生终端，不能替代 Android 界面的像素级或协议验收。

## 可以操作

- 在 16:10、4:3、3:2、16:9 间切换，旋转横竖屏；自定义 360–2560 CSS px 宽高，支持自适应与 1:1 预览。
- CLI 与 AI 窗口混排，筛选、搜索、打开已有会话、新建、展开、收起和恢复。
- 拖动六点手柄调整顺序；自由布局可移动和缩放卡片，点击卡片置于前方。
- 列数可选自动、1、2、3、4、5 列，按个人偏好保存。自动模式根据可用宽度选择 1–3 列，指定列数在平板上保持；工作区不足 550 CSS px 时临时退回单列，恢复宽屏后仍用原选择。
- 小窗口内部按至少 560 CSS px 的参考宽度等比缩小，保留 CLI／AI 的界面结构，不单独挤压字体或工具栏；外层拖动、展开和收起按钮保持尺寸。展开后按实际可用宽度恢复到接近或完整 100%，窗口标题条显示缩放百分比。
- 点击“填充示例”打开至少两行示例窗口，方便比较 3／4／5 列；这些新增窗口仍是本地模拟内容。
- CLI 在终端行中按 Enter 提交，支持 `pwd`、`help` 和 `clear` 的模拟结果。AI 保留多行文本输入，Enter 换行，点击原有发送图标提交；生成中可点击停止。
- 云朵菜单可演示请求／释放控制权；只读或冻结历史时不允许输入。点击或拖动窗口不会自动抢控制权，其他窗口的状态独立保留。
- AI 工具栏可搜索当前消息、查看示例文件／变更／用量，支持引用到草稿与演示文件引用。复制和终端粘贴使用原型内存剪贴板，不读写系统剪贴板。
- 模拟软键盘并将当前输入区滚动到可见范围；支持浅色和深色主题。
- 浏览器允许本地存储时保存布局、主题、新建与收起状态；不保存命令、消息或输入草稿。浏览器禁止存储时仍可使用，刷新后恢复默认。
- 聚焦拖动手柄后按 Alt + 方向键排序。关闭卡片只收起视图，不表示结束远程进程。

预览尺寸是页面布局的 CSS 像素，与平板物理分辨率不同；嵌入预览具有独立 viewport，因此切换比例会实际触发响应式布局，而不是只拉伸图片。自由布局保留原位置，窄屏平铺时不删除自由布局数据。

## 默认小窗口比例

建议默认“屏幕适配”，依据当前应用工作区的可用宽高、列数与行数计算，而不是直接复制整块屏幕的物理比例。两台同为 16:10 的平板，在分屏、导航栏或工具栏占用不同的情况下，可用工作区比例也会不同。

计算规则：

```text
窗口宽度 = (工作区可用宽度 − 列间距) / 列数
窗口高度 = (工作区可用高度 − 行间距) / 目标行数
窗口宽高比 = 窗口宽度 / 窗口高度
```

3–5 列默认以两行总览计算；1–2 列根据当前窗口数量取一或两行。自动比例限制在 `3:4` 至 `16:10` 之间，避免窗口过分狭长。原型显示实际采用的比例，可随时固定为 `4:3`、`3:2`、`16:10`、`1:1` 或 `3:4`。

| 场景 | 推荐取向 |
| --- | --- |
| 2 列日常操作 | 充分使用当前可用高度，保留终端与对话的阅读面积 |
| 3 列两行 | 常接近 4:3，兼顾窗口数量和可读性 |
| 4 列两行 | 常接近正方形，适合并排观察多会话 |
| 5 列两行 | 常接近 3:4，适合状态总览；展开单窗再输入 |

上述取向基于横屏平板的设计选择，不是硬件标准。固定比例需要一个通用起点时可选 4:3；AI 长对话也可选 3:4。设置 5 列会显著缩小文字，本原型不把缩小后的控件宣称为可舒适触控，外层展开入口保持原尺寸。

## 验证

使用仓库 `ai-web` 已安装的 Playwright 和本机 Edge 执行：

```powershell
node scripts/test_tablet_workspace.cjs
```

可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定现有 Chromium 可执行文件，通过 `TERMLINK_DESIGN_TEST_OUTPUT` 指定截图与结果输出目录。脚本不下载浏览器、不安装依赖。

回归检查屏幕比例、横竖屏、窄窗口和超宽窗口、2–5 列与 6 种窗口比例组合、等比变换、展开恢复可读尺寸、列数和比例保存、筛选、新建、输入、放大、软键盘、排序、移动、缩放、收起与恢复和 HTML 转义；同时检查 CLI 终端内输入与快捷键、AI 工具栏和多行输入、只读／冻结状态及窗口间隔离。要求无脚本异常、无外部 HTTP 请求。
