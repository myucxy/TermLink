# 快速开始

本文面向使用安装包的用户。修改源码请看[开发与构建](../development/BUILDING.md)。

## 准备

- 一台运行受支持 Windows x64 系统的电脑；安装器会检查系统版本和 ConPTY 能力。
- Android 8.0 / API 26 或更高版本的手机。
- 两端都能访问的 HTTPS TermLink 服务地址，反向代理需支持 WebSocket。
- 同一个 TermLink 账号。使用 AI 时，还需要在 Windows 安装并登录对应 Agent。

TermLink 服务账号和 AI 供应商账号是两套身份；登录 TermLink 不会自动获得模型额度或为 Agent 登录。

## 1. 部署或选择服务端

已有服务地址时可直接进入下一步。自部署从 [Server README](../../server/README.md)开始，运行拓扑是外部 HTTPS 反向代理、TermLink Server、PostgreSQL。

生产部署核对镜像版本和 digest，配置公网地址与受保护的数据库密码。首次管理员密码按部署说明获取，没有公开固定密码。随后按需配置注册或邀请码策略。

当前使用 **Relay Only**，不需要为 LAN/NAT 测试准备网络。若已有部署原先允许直连，需核对服务端实际策略；阅读文档不会改变已部署的配置。

## 2. 安装与登录

从 [AppShip](https://appship.kget.cc:8910)获取 Windows 和 Android 包，参照[发布记录](../releases/README.md)核对版本和签名说明。安装后将两端服务地址设置为同一地址，使用同账号登录。

Windows 保持 Agent 在线，Android 设备页应出现该电脑。如果暂未出现，先检查登录是否有效、服务地址是否一致、Windows Agent 状态与代理的 WebSocket 转发，再刷新设备列表。

Windows 当前发布记录使用自签名开发证书，新电脑可能出现发布者信任提示。证书信任和 SmartScreen 信誉不同；不要把关闭安全检查、替换签名证书当成正常升级步骤。

## 3. 使用 CLI

在 Android 设备卡片点击 CLI，选择电脑支持的终端命令。默认工作目录由 Windows 创建；支持时可以指定其他目录。

- CLI 页显示手机打开的终端视图；设备页查询电脑对应的会话目录与真实状态。
- 输入、快捷键和终端鼠标操作仍由原 CLI 页面处理。
- 收起手机视图、结束远程进程、清理失效会话是不同操作，以按钮说明和电脑回执为准。
- 电脑确认离线时不会将缓存正文继续当作在线会话展示。
- “按手机窗口调整”是显式尺寸操作，不把键盘弹出/收起理解为任意自动调整电脑窗口。

## 4. 使用 AI

先在 Windows 设置中检测 AI Agent，再从 Android 的设备卡片或 AI 页创建对话。只显示当前电脑支持的可创建能力；模型、推理强度和权限模式来自各 Agent 的实际能力。

默认目录由 Windows 按会话创建。若从文件目录进入新建 AI，会带入对应路径；创建后进入聊天页。

TermLink 原生 AI 对话中的附件、审批、问题回答、停止生成和恢复历史，均以对应 Agent 支持情况为准。认证失败或额度限制需要在该 Agent/供应商侧处理。

ZCode 桌面远控需在 Windows 配置完整远控地址，手机从 AI 入口打开其网页。这个页面使用 ZCode 自身的会话、模型和权限交互，不与 TermLink 的结构化对话混用。

## 5. 文件、更新与排查

- 设备卡片的文件入口浏览电脑文件；AI 输出包含可解析文件引用时，可跳转到同设备的对应目录。
- 安装升级前保存工作。当前更新可能停止 Windows 会话，不承诺不中断正在生成的 AI 任务。
- 下载成功、安装器启动成功、安装成功和新版本正常上线是不同阶段。报错时记录版本、阶段、错误码及脱敏日志。
- 有账号隔离、审批绕过或更新验签方面的问题，请按 [SECURITY.md](../../SECURITY.md)私密报告。
