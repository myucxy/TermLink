# TermLink 0.3.15 / 145

修复 Windows 旧设备身份缺失时无法重新登录、CLI 同步超时后长期状态待确认，以及安卓结束会话后 Windows Terminal 保留退出窗口的问题。Android 增加会话目录重新确认入口。

## Windows

- 重新授权后，旧设备校验返回 `401 UNAUTHENTICATED` 时，以新授权凭据、原设备 ID 和原密钥向现有接口重新登记；只有明确创建成功并通过后续设备校验，才保存登录。注册冲突、禁用、错误签名和异常响应不会直接放行；保留原 PC 标识及其他账号身份缓存。
- 会话元数据请求超时不会再结束后台同步任务；保留待同步状态并重试，继续发布 PC 心跳，正常关闭运行时或账号授权失效时仍停止。
- 手机新建的普通/自定义 CLI 显式使用 TermLink 专用终端配置的 `closeOnExit: always`。实际 Shell、参数、目录和会话身份保留；结束对应 SessionHost 后关闭它的标签页，最后一个标签页结束时关闭窗口，其他会话继续运行。
- 开发用 Windows Terminal Fragment 生成脚本同步配置退出即关闭。窗口规则适用于升级后新建的会话，不追溯修改已打开标签页或用户默认配置。

## Android

- 会话状态待确认时可点击“重新确认”，刷新期间禁用重复点击；主机确认成功后恢复正常控制获取流程。
- 目录请求超时、Relay 连接代次切换和短暂 HTTP 408/429/5xx 不再被当作会话已删除。仅在原可信设备、交换公钥和密钥 epoch 一致时保留现有视图；身份变化、撤销及无效目录仍拒绝使用。
- 单次请求期限不会终止前台目录轮询；手动刷新超时后结束确认中状态，允许再次操作。

## 验证与范围

- Android 492 项应用单测、4 项加密目录协议测试通过；lint 为 0 errors。手机模拟器验证重新确认、等待期间不提前获取控制、重复点击保护、确认后恢复、原生引擎与其他 PC 保留。
- Windows 心跳/同步任务、会话故障隔离、文件操作、安装配置及旧身份恢复验证通过。隔离 PostgreSQL/Redis 验证缺失设备重建、账号隔离、不同密钥冲突，以及禁用/撤销记录不被覆盖。
- 真实 Windows Terminal 双标签页测试通过：使用生产 SessionRegistry 终止对应 SessionHost 和子 Shell，目标标签移除、另一会话存活，最后一个标签结束后窗口关闭。
