# AI 文件打开所在目录

2026-10-04 实现。Android 原生 AI 会话的文件列表和真实文件预览页，在保存/关闭按钮旁显示紧凑文件夹按钮，
无障碍名称为「打开所在目录」。只有正文 HTML 代码片段而未落盘的预览不显示此入口。

点击后从当前会话的 PC、工作目录和文件相对路径解析父目录，经既有远程文件浏览权限读取成功才导航。
文件页继续使用原目录结构、上级、搜索、收藏、终端和 AI 新建菜单；目标文件在已加载条目中高亮并滚动定位。
顶部显示文件名和「返回对话」，系统返回在起始父目录也回原会话。会话草稿不被清空或发送。
电脑离线、目录移走、权限不足时保留对话并显示失败；切换页面/会话/主机后晚到的读取不能再次把用户带走。

路径从原生会话解析，不接受网页传入任意电脑身份。拒绝越界绝对路径、`..`、ADS 和不支持的网络/设备路径。
当前 Windows Agent 产物接口本来只接受工作区文件，目录动作保持这一边界；原文件浏览页仍执行自身授权。
不修改服务端协议、Windows 会话进程或 CLI 页面布局。ZCode 桌面远控网页不注入原生文件能力。
