# TermLink 功能演示

操作画面 2 倍速；旁白、字幕按正常速度。TUI 两端共用同一加速时间轴。

按语言进入 [中文](中文/README.md) 或 [English](English/README.md)，再按功能目录选择单独片段。也可打开 [网页目录](index.html)。

每种语言包含 2 部完整演示、15 段功能介绍和 5 部此前产品视频。配套烧录字幕、SRT 与封面；终端演示为 1600 × 1800，产品竖版为 1080 × 1920，均为 30 fps。

英文版提供英文标题、介绍卡片、旁白和字幕；实录界面及真实模型回复保留原语言。中文沿用已有旁白音频，未变速。加速操作之后保留结果画面供解说。

TUI 录制于 2026-10-17：Windows Terminal + pwsh 7.6.6，Windows 0.3.5.135，安卓模拟器 DEV 0.3.4/133（含当前已复核修复）。功能总览录制于 2026-10-06，使用当时的 DEV 界面。两组演示都通过服务器中转。

Codex 0.162.1、Claude Code 2.1.296、OpenCode 1.19.0 均实际输入 hi 并收到回复。沿用现场 CLI 服务配置：Claude Code 使用 glm-5.3，Codex / OpenCode 使用 gpt-6.1-sol；CLI 名称不代表同名厂商模型。OpenCode 仅在录制进程中切换模型，未改写全局配置。

中文旁白来自已有 XiaoxiaoNeural 音频；英文旁白使用 JennyNeural 正常语速合成。轻电子背景音乐由本地脚本原创生成。

这些视频展示所列操作，不替代全部功能回归验收。图片与录屏中的设备名已获维护者同意公开。

此前产品短片与 CLI 双向同步演示也已按同样规则重剪，分别归入 `06_产品视频` 和 `01_CLI终端`。此前两部原速长片收在[原速存档](archive/README.md)。
