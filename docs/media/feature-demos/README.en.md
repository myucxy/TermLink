# TermLink feature demos

Screen activity runs at 2x. Narration and subtitles keep their normal pace. Both TUI panels share one retimed source.

[English catalogue](English/README.md) · [中文目录](中文/README.md) · [Browse all demos](index.html)

Each language contains two complete demos, fifteen feature clips, and five previous product videos, with burned-in captions, SRT files, and covers. Terminal demos are 1600 × 1800; portrait product videos are 1080 × 1920. All run at 30 fps.

The English edition has English titles, guide cards, narration, and subtitles. Recorded application screens and real replies keep their original language. Result screens are held after accelerated activity so the narration can finish naturally.

The TUI recording uses Windows Terminal with pwsh 7.6.6, Windows client 0.3.5.135, and an Android emulator running DEV 0.3.4/133 with current reviewed fixes. It was recorded on October 17, 2026. The feature overview uses the DEV interface recorded on October 6. Both use server relay.

Codex, Claude Code, and OpenCode each received a real hi prompt and returned a real response. Existing provider settings were used: glm-5.3 for Claude Code and gpt-6.1-sol for Codex / OpenCode. CLI branding does not identify the underlying model provider. The OpenCode model override applied only to the recording process.

Existing Chinese speech was reused at its original pace. English speech uses JennyNeural at normal speed. Background music was synthesized locally without third-party songs or samples. These demonstrations do not replace a full regression test.

Previous product shorts and the bidirectional CLI demo have also been retimed and localized. Earlier long-form originals are in the [archive](archive/README.md).
