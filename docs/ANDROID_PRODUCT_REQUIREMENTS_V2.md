# TermLink Android 产品需求（V2）

> 状态：已确认，进入第一阶段开发（2026-08-06）  
> 适用范围：`android/app` 产品壳、会话终端和本地显示设置

## 1. 产品目标

TermLink Android 是同一账号下 Windows PC 终端的移动查看与操作入口。交互参考
[Termux App](https://github.com/termux/termux-app) 的终端优先理念和键盘输入方式，
但使用 TermLink 自己的导航、状态和视觉，不复制 Termux 的代码或界面。

## 2. 需求范围

### 2.1 认证与账号

- 未登录时首次进入登录页。
- 登录页提供账号注册入口。
- 登录信息持续保存，直到用户主动退出，或服务端令牌按正常认证规则失效。
- 不实现“30 天固定过期”；密码只在提交期间驻留内存，不落盘。

### 2.2 设备页

- 仅展示当前账号的 Windows PC，不展示 Android/手持客户端。
- PC 在线使用绿色状态灯，离线使用灰色状态灯。
- PC 是一级分组；每个 PC 下按会话显示活动状态：运行中为高亮，
  中断/关闭为灰色，并可进入会话页。
- 不在此页展示“申请控制”。

### 2.3 会话页

- 页面核心是终端内容，终端占据可用空间的最大部分。
- 多个会话使用左右滑动的整页切换，不显示一排 Tab 按钮，也不显示 Tab 滚动条。
- 顶部只保留紧凑的 `PC 名称 · 会话名称` 和红/绿/灰状态灯；不显示“返回设备”、
  “终端已连接”等冗余文案。
- 终端直接接收正常键盘/IME 输入，不使用独立的“输入命令框”或发送框。
- 快捷输入 Dock 位于黑色终端区域内：小尺寸、半透明、可收起；支持 Esc、Tab、Enter、
  方向键、Ctrl+C 等常用键，但快捷键不是唯一输入方式。
- 所有已打开且活动的会话都持续接收输出，切换页面不应关闭其他会话的实时流。
- 终端采用 Termux 引擎适配层，保持远程会话、只读/控制状态和历史恢复能力。

### 2.4 设置页

- 顶部信息卡直接显示当前登录用户名或邮箱，不再单独显示“账号”分组、
  “查看已登录身份”说明或重复的账号跳转入口。
- 信息卡同时显示服务器连接、默认访问权限和输入安全状态；退出登录与当前身份放在同一张卡片内。
- 版本检查放在“关于”区域，显示版本、作者和更新结果。
- 展示连接状态和应用外壳主题。
- 提供终端显示设置：字体大小、行间距、前景色和背景色。
- 颜色使用 RGB（0–255）输入并实时预览，保存到本地偏好；不上传密码或颜色设置。
- 保留自定义快捷键入口（当前已有快捷键动作作为第一批默认项）。

## 3. 第一阶段开发内容

1. 新增终端显示偏好模型和 SharedPreferences 持久化。
2. 设置页加入字体大小、行间距、前景/背景 RGB 编辑器。
3. Termux 终端视图支持字体大小和行间距参数，颜色通过 `TerminalThemeV1` 应用。
4. 会话页移除“申请控制”和释放/粘贴操作条，改为终端内半透明快捷 Dock；
   打开会话时自动请求控制租约，以便直接输入命令。
5. 移动端移除会话切换按钮行，仅保留 HorizontalPager 左右滑动。
6. 设备页过滤 Android 设备，仅渲染 Windows PC 和其会话分组。
7. 允许多个实时会话同时保持连接，不因切换页面关闭其他会话。

## 4. 验收标准

- 清除应用数据后启动，首屏为登录页；注册入口可见。
- 登录后设备列表中不存在 `DeviceType.ANDROID` 项；每台 PC 有明确在线/离线灯。
- 从设备页进入会话，左右滑动可切换会话，不出现 Tab 条或滚动条。
- 终端可直接唤起系统键盘并发送字符；快捷 Dock 可收起/展开且不遮挡主要终端内容。
- 至少两个会话同时打开时，切换回来仍能看到各自持续接收的输出。
- 修改字体大小、行间距、RGB 后重新打开会话，设置仍生效且终端颜色可见变化。
- 退出登录后回到登录页；重新登录不要求等待 30 天或执行额外过期流程。

## 5. 非目标与后续

- 本版本不复制 Termux 的应用导航、插件体系或本地 Shell 管理。
- 快捷键的更多组合键和真正的按键映射列入后续阶段；当前阶段支持 Dock 按键选择、排序和标签编辑。
- 服务端控制租约仍是安全边界；第一阶段由打开会话自动申请，失败时显示安全错误。
