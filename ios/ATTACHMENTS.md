# AI 附件恢复与目录入口

2026-10-25，本轮继续对齐 Android 的文件目录操作和 AI 附件生命周期。

## 从文件目录创建 AI

文件浏览页的当前目录和子目录菜单均可选择“在此新建 AI 对话”；当前目录还提供原有终端命令和目录 ZIP 下载入口。创建表单携带明确的电脑 ID 和目录，使用普通目录模式，不以第一台在线电脑替换所选电脑，也不自动改用托管目录。

只有当前仍在线、允许远程路由且声明 `ai_agent_v1` 的电脑可创建。表单打开后仍会刷新 Agent 目录，创建前再次检查电脑与现有请求仲裁。所选电脑离线／关闭路由／缺少能力时不能创建；取消不会发送创建请求。成功后回到新 AI 会话。

## 附件缓存与恢复

- 文件、照片和相机结果先保存到应用的私有加密缓存，再开始上传；上传不再依赖原文件选择器或照片临时地址长期有效。
- 内容使用 AES-GCM 加密，密钥放在 `WhenUnlockedThisDeviceOnly` Keychain 项。缓存按现有服务／账号 scope 隔离，AAD 绑定 scope 与随机附件 ID。缓存目录排除系统备份，文件使用完整保护，不保存明文副本；用户文件名不参与缓存路径。
- 附件元数据继续使用 `SecureState` 的账号加密存储，记录电脑、会话、host、controlVersion、同一附件 ID、大小和 SHA-256。
- 单附件最多 20 MiB、每会话最多 5 项且总计 50 MiB，还需满足主机声明的更小上限；账号缓存总量最多 256 MiB。缓存加解密与文件 I/O 在独立 actor 执行。
- 恢复只发布“已恢复 · 待重试”状态，不触发上传或发送。即便上次已就绪，也需用户点击重试确认主机当前状态。电脑／host／控制版本不符时保留本地记录并拒绝重试，用户可移除后重新选择，不自动重绑定。
- 后台或断连中断的上传保持可重试记录；退出登录不会将缓存交给其他账号。发送、移除或删除历史确认后清理相应缓存；若进程在清理前结束，下次恢复删除无元数据引用的孤立文件。

## 上传协议与确认

重试沿用同一附件 ID、名称、大小和摘要，以 `attachment.begin` 返回的偏移为准。失去分块回执时，不使用旧本地偏移盲目追加；失去 commit 回执时，begin 若确认已就绪，就直接恢复就绪状态，不重复上传。

缓存解密后重新核对大小和摘要。非法／超界／小数偏移、错误分块 ACK 或未确认的 commit 都不能产生“就绪”。每次请求和回执后检查当前账号运行期、电脑、会话、host 和控制版本；变化后停止上传。发送仍需主机成功回执，恢复附件绝不自动发送。

主机因过期或重启已删除附件、会话不再存在或控制版本已变时，需要移除后重新选择。此处没有绕过主机过期或权限规则。失败信息显示在附件卡片，可由用户重试或移除；图片格式、Agent 特定限制继续由主机执行。

## 验证边界

新增测试覆盖：

- 加密文件与元数据重建后，原照片／文件临时地址已删除仍能读取缓存；账号、密钥、附件 ID、摘要、长度或密文变化时拒绝读取。
- 路径、符号链接、重复 ID、文件变化、缓存预算、孤立清理和已清空会话不挤占恢复名额。
- 模拟主机丢失 chunk／commit 回执后，用主机偏移和原 ID 恢复，完整字节一致；错误 ACK／commit 不能标记就绪。
- 原电脑／会话／host／控制版本绑定和目录入口的电脑资格检查。
- iPhone／iPad 未登录创建表单无法创建会话，保留现有导航、许可、快捷键 UI 回归。

模拟协议 fixture 验证重试算法，不能替代真实 Relay、Windows Agent、相册／相机权限及设备后台生命周期联测。当前仍需这部分真实环境验收；本轮没有部署服务器或改变原生核心产物。

最终代码在 iPhone／iPad 模拟器各通过 91 项测试（本轮新增 18 项逻辑测试，原有 3 项 UI 测试扩展未登录创建检查），无失败或跳过；设备 arm64 无签名 Release 编译通过。
