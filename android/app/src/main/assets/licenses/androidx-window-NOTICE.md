# AndroidX WindowManager

TermLink uses `androidx.window:window:1.5.1` to observe folding features from the Android window system.
Its original Apache-2.0 license text, copied unchanged from the resolved Google Maven AAR, is retained in
`androidx-window-LICENSE.txt`. AndroidX window testing helpers are test dependencies and are not part of release APKs.

- Release notes: https://developer.android.com/jetpack/androidx/releases/window
- Source: https://android.googlesource.com/platform/frameworks/support/+/androidx-main/window/
- Artifact: https://dl.google.com/dl/android/maven2/androidx/window/window/1.5.1/window-1.5.1.aar
