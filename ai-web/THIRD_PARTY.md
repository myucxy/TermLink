# AI Web dependencies

Own UI and protocol implementation; no HAPI or ZCode product source was copied.

React, React DOM, react-markdown, remark-gfm, React Virtuoso, Vite and React type declarations are MIT-licensed. TypeScript and Playwright are Apache-2.0. Package versions are pinned in package.json and package-lock.json. Only the ordinary React Virtuoso package is used, not its separately licensed Message List product.

The build must ship the licenses for runtime dependencies with the Web assets. See the generated `third-party-notices.txt`. Development tools are not bundled into the product.
