TermLink legacy V1 snapshot compatibility width data

ProductionTerminalHistoryProducer.cs retains Unicode 15.0.0 zero-width and
wide-character ranges originally taken through Termux's WcWidth.java at:
https://github.com/termux/termux-app/tree/3df69d1da197dd9bd71a3bafd902dffd720576b4

The upstream WcWidth.java identifies jquast/wcwidth as its source. The 343
zero-width and 121 wide-character ranges were checked on 2026-10-08 against
the corresponding Unicode 15.0.0 tables at the following pinned revision;
all range values and their order match. No rendering or protocol behavior
was changed as part of this attribution update.

https://github.com/jquast/wcwidth/blob/1b9b6585b0080ea5cb88dc9815796505724793fe/wcwidth/table_zero.py
https://github.com/jquast/wcwidth/blob/1b9b6585b0080ea5cb88dc9815796505724793fe/wcwidth/table_wide.py

It covers that upstream material, not all TermLink code or all historic
Termux-derived material. Original Termux provenance and the remaining
compatibility review are recorded in docs/archive/TERMUX_CLEANUP_20261008.md.
