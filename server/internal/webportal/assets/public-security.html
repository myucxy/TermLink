SECURITY BOUNDARY

安全说明

{{.Description}}

01

终端正文端到端加密

Relay 只处理路由与密文，不在 Web 页面、管理台或服务端日志展示终端输出、命令、快照和历史正文。

02

设备身份独立

每台 Android 与 Windows 设备使用独立身份和密钥。撤销一个设备不会把其他设备的密钥或缓存共享给它。

03

本地优先

Windows 本地用户始终拥有最高控制权。网络、账号或 Relay 故障不能被用来终止本机 Shell。

04

最小公开信息

公开状态页不披露主机名、数据库、队列、服务拓扑或内部错误；账号页只展示完成操作所需的元数据。

DATA VISIBILITY

数据可见性边界

服务端可见
账号归属、设备状态、会话标识、路由、租约和必要审计元数据。
服务端不可见
终端命令、输出正文、端到端密钥、设备私钥和本地凭据。
用户可控制
设备撤销、远程访问策略、控制租约、历史生命周期和账号安全设置。
