PRODUCT

不是远程桌面，是你的真实终端。

TermLink 保留 Windows Terminal、ConPTY 和本地 Shell 的所有权，只把有序终端流安全送到手机。

01

实时观看

ANSI、颜色、光标、宽字符和全屏 TUI 以原始终端语义传输，Android 独立渲染。

02

短时控制

默认只读。申请短时租约后输入文本与控制键；本地 Windows 键盘随时立即抢回。

03

可靠恢复

输入 ID 去重、累计 ACK、Gap 和背压共同保证重连后不重复执行已经确认的输入。

SECURITY BY DESIGN

Relay 只看见密文和路由。

设备通过 OIDC 身份和独立设备密钥证明归属；首版同账号设备自动登记和发现。服务器负责路由、短时控制租约和审计，但不持有终端正文解密密钥。

E2EE
X25519 + ChaCha20-Poly1305，正文对 Relay 不可见。
Device proof
每个敏感请求同时证明账号身份与设备私钥持有权。
Local first
远程订阅、账号状态或网络故障都不能终止本地 Shell。

SELF-HOSTED

把控制面部署在你信任的位置。

Docker Server 集成 PostgreSQL、Valkey、OIDC、TLS 与 Realtime Relay。生产部署使用只读 RootFS、非 root 容器和文件型 Secret。
